Čo je Vim

Vim (Vi IMproved) je textový editor, ktorý beží v termináli a nájdeš ho takmer na každom Linuxe, serveri aj v Git Bashi na Windows. Na rozdiel od bežných editorov je modálny: klávesy robia iné veci podľa toho, v akom režime práve si. V jednom režime písmená píšu text, v inom sú to príkazy („zmaž slovo“, „skoč na koniec riadku“).

Na začiatku to pôsobí zvláštne, ale výhoda je veľká: ruky nemusia opustiť klávesnicu a úpravy sa skladajú z krátkych „viet“ ako dw = delete word. Keď sa naučíš pár slovies a pár pohybov, kombinácie dostaneš zadarmo.

Najdôležitejšia rada: keď nevieš, kde si, stlač Esc (aj dvakrát). Vždy ťa vráti do normálneho režimu, odkiaľ sa dá všetko.

Inštalácia a spustenie

LinuxInštalácia

Na mnohých distribúciách je predinštalovaný len okresaný vim-tiny (alebo vi). Plnú verziu doinštaluj:

# Debian, Ubuntu, MX Linux, Mint
sudo apt install vim
# verzia s podporou systémovej schránky (registre "+ a "*)
sudo apt install vim-gtk3
# Fedora
sudo dnf install vim-enhanced
# Arch
sudo pacman -S gvim

Či verzia podporuje schránku zistíš príkazom vim --version | grep clipboard – musí tam byť +clipboard, nie -clipboard.

Nastavenie Vimu ako predvoleného editora (napr. pre git commit, crontab -e, visudo):

sudo update-alternatives --config editor
# alebo len pre seba, do ~/.bashrc:
export EDITOR=vim
export VISUAL=vim
# a pre git:
git config --global core.editor vim

WindowsInštalácia

Možnosti:

  • Git for Windows – Vim je súčasťou Git Bashu, stačí napísať vim.
  • winget – nainštaluje Vim aj grafický gVim:
winget install vim.vim
  • WSL – v Ubuntu pod Windows rovnako ako v Linuxe (sudo apt install vim).

Konfiguračný súbor je vo Windows %USERPROFILE%\_vimrc (s podčiarkovníkom) alebo %USERPROFILE%\vimfiles\vimrc. V Git Bashi sa používa linuxový ~/.vimrc.

Vo Windows Termináli Ctrl+v vkladá zo schránky, takže blokový výber spúšťaj cez Ctrl+q (robí to isté).

Spustenie

vim                    # prázdny editor
vim subor.txt          # otvorí (alebo vytvorí) súbor
vim +42 subor.txt      # otvorí a skočí na riadok 42
vim +/hladaj subor.txt # otvorí na prvom výskyte slova
vim a.txt b.txt        # viac súborov (prepínanie :bn / :bp)
vim -o a.txt b.txt     # pod sebou v oknách (-O vedľa seba)
vim -p a.txt b.txt     # každý v samostatnej karte
vim -d stary new       # porovnanie dvoch súborov (vimdiff)
vim -R subor.txt       # len na čítanie (to isté ako view)
ls -l | vim -          # otvorí výstup príkazu
sudoedit /etc/hosts    # bezpečná úprava systémového súboru

Interaktívny tutoriál

Vim má zabudovaný kurz na cca 30 minút, ktorý ťa prevedie základmi priamo v editore. Ak ho máš v slovenčine, spustí sa sám podľa jazyka systému:

vimtutor
vimtutor sk     # vynútiť slovenskú verziu

Pomoc priamo vo Vime: :help, :help dw, :help :s, :help 'number' (nastavenia v apostrofoch). V pomocníkovi skáčeš na odkaz Ctrl+], späť Ctrl+o, zavrieš :q.

Režimy

Všetko sa točí okolo normálneho režimu. Z neho odbočíš do iného režimu, urobíš tam, čo treba, a Esc ťa vráti späť. Aktuálny režim vidíš vľavo dole (-- INSERT --, -- VISUAL --…). V normálnom režime tam nie je nič.

Píšeš text ako v bežnom editore.
Vstup: i a o I A O c…
⌨️ Normálny (Normal)

pohyb, mazanie, kopírovanie.

Typická chyba začiatočníka je ostať stále vo vkladacom režime a pohybovať sa šípkami. Funguje to, ale prichádzaš o celú silu Vimu. Zvykni si: napíšeš kúsok textu → Esc. Normálny režim je „domov“, vkladací len krátka návšteva.

Najznámejšia otázka o Vime. Najprv Esc, potom:

Operátory a textové objekty – „gramatika“ Vimu

Toto je srdce Vimu. Väčšina úprav sa skladá ako veta:

[počet]  operátor (sloveso)  +  pohyb alebo textový objekt (predmet)

Stačí sa naučiť pár operátorov a pár pohybov – a každý operátor funguje s každým pohybom.

Operátory (slovesá)

dzmazať (delete) – aj vystrihne
czmeniť (change) = zmazať a prejsť do vkladania
ykopírovať (yank)
> <odsadiť / zrušiť odsadenie
=automaticky odsadiť
gU / guna VEĽKÉ / malé písmená
g~prepnúť veľkosť písmen
gqpreformátovať (zalomiť)
!prefiltrovať cez externý príkaz

Zdvojený operátor = celý riadok: dd, cc, yy, >>, gUU.

Textové objekty

Pohyb závisí od toho, kde stojí kurzor. Textový objekt nie – označí celú vec okolo kurzora. Používajú sa len po operátore (alebo vo vizuálnom režime). i = inner (len obsah), a = a / around (aj s okolím – medzerou, úvodzovkami, zátvorkami).

[obsah [ ]aj so zátvorkami

Príklady – kurzor môže byť kdekoľvek vnútri:

ci"     # prepíš text v úvodzovkách:   "starý text"  →  "|"
da(     # zmaž zátvorku aj s obsahom:  f(a, b)  →  f
ci{     # prepíš telo funkcie / bloku
yap     # skopíruj celý odsek
dit     # vyprázdni HTML tag:  <p>text</p>  →  <p></p>
diw     # zmaž slovo pod kurzorom (aj keď stojíš v jeho strede)
daw     # zmaž slovo aj s medzerou – veta ostane úhľadná
>i{     # odsaď obsah bloku { }
vi[     # označ obsah hranatých zátvoriek
Prečo ciw a nie cw? cw mení len od kurzora po koniec slova. ciw mení celé slovo, nech stojíš kdekoľvek – a dá sa zopakovať bodkou na iných slovách.

Bodka .

Bodka zopakuje poslednú zmenu – všetko od operátora alebo vstupu do vkladania po Esc. Kombinuje sa s hľadaním:

# Premenovať niekoľko výskytov slova „pocet“ na „count“, ale nie všetky:
/pocet<Enter>      # nájdi prvý výskyt
ciwcount<Esc>      # zmeň ho
n                  # ďalší výskyt
.                  # zopakuj zmenu – alebo znova n, ak tento chceš preskočiť
n.n.nn.            # …a tak ďalej

# Pridať bodkočiarku na koniec viacerých riadkov:
A;<Esc>            # na prvom riadku
j.j.j.             # na ďalších

Trvalá história zmien aj po zatvorení súboru – pozri undofile v časti .vimrc.

Bez podpory schránky (-clipboard) vlož text cez terminál (Ctrl+Shift+v) – predtým :set paste, aby sa neposunulo odsadenie.

Častý problém: „p vloží nesprávny text“

Skopíruješ slovo (yiw), potom zmažeš iné, ktoré chceš nahradiť (diw) a p vloží to zmazané. Riešenia:

"0p         # vlož posledné KOPÍROVANIE
"_diwP      # zmaž do čiernej diery, potom vlož
viwp        # označ slovo a prepíš ho vloženým

Vizuálny režim

Bežný výber ako myšou.

V – po riadkoch

Vždy celé riadky.

Ctrl+v – blok

Obdĺžnik / stĺpec cez viac riadkov.

Regulárne výrazy

Vim používa vlastnú syntax, v ktorej veľa špeciálnych znakov treba „odescapovať“ spätnou lomkou. Prefix \v (very magic) zapne syntax podobnú bežným regexom, \c vypne rozlišovanie veľkosti.

/\v\d{3}-\d{4}s very magic: 3 číslice, pomlčka, 4 číslice
/\v(chyba|error)jedno alebo druhé slovo
/\s\+$medzery na konci riadku

Makrá

Makro nahrá postupnosť kláves do registra a potom ju prehrá. Ideálne na opakujúce sa úpravy, ktoré sa nedajú urobiť jedným :s.

KlávesČo robí
qazačne nahrávať do registra a (vľavo dole recording @a)
qukončí nahrávanie
@aprehrá makro a
@@zopakuje naposledy prehraté makro
50@aprehrá 50-krát (zastaví sa pri prvej chybe, napr. na konci súboru)
:5,20norm @aprehrá makro na každom riadku 5–20
:'<,'>norm @ana každom označenom riadku
qApokračuje v nahrávaní – pridá na koniec makra a

Príklad: CSV na HTML zoznam

# Vstup:                     Výstup:
# Jablko,5                   <li>Jablko – 5 ks</li>
# Hruška,12                  <li>Hruška – 12 ks</li>

qa            # začni nahrávať
0             # začiatok riadku (makro má fungovať odkiaľkoľvek)
i<li><Esc>    # vlož začiatok tagu
f,            # na čiarku
s – <Esc>     # nahraď čiarku pomlčkou
A ks</li><Esc>  # koniec riadku
j             # posuň sa na ďalší riadok – pripravené na opakovanie
q             # koniec nahrávania
100@a         # zvyšné riadky
Tipy pre spoľahlivé makrá: začni pohybom na známe miesto (0, ^), používaj pohyby podľa obsahu (f, w, /) namiesto lll, a na konci sa posuň na ďalší riadok. Makro je obyčajný text v registri – "ap ho vloží do súboru, môžeš ho upraviť a "ayy uložiť späť (bez znaku konca riadku: 0"ay$).

Ak si omylom spustil nahrávanie (recording @q vľavo dole), stačí stlačiť q.

Konfigurácia .vimrc

Nastavenia napísané počas práce (:set …) platia len do zatvorenia. Trvalé nastavenia patria do súboru ~/.vimrc (Linux, Git Bash) alebo %USERPROFILE%\_vimrc (Windows). Otvoríš ho zo samotného Vimu príkazom :e $MYVIMRC a po úprave načítaš :source $MYVIMRC (alebo :so %).

Rozumný základ s komentármi – skopíruj a uprav podľa seba:

" ~/.vimrc – komentár začína úvodzovkou

" ----- Základ -----
set nocompatible            " plný Vim, nie režim kompatibility so starým vi
filetype plugin indent on   " rozpoznávanie typu súboru, pluginy a odsadenie podľa jazyka
syntax on                   " farebné zvýraznenie
set encoding=utf-8
set hidden                  " prepínanie bufferov bez nutnosti ukladať
set backspace=indent,eol,start  " Backspace maže všetko
set mouse=a                 " myš (klikanie, označovanie, posúvanie)
set clipboard=unnamedplus   " y a p používajú systémovú schránku (treba +clipboard)
set history=1000
set updatetime=300

" ----- Vzhľad -----
set number                  " čísla riadkov
set relativenumber          " relatívne čísla (aktuálny ukáže skutočné)
set cursorline              " zvýrazniť riadok s kurzorom
set showcmd                 " ukázať rozpísaný príkaz vpravo dole
set showmatch               " bliknúť párovú zátvorku
set laststatus=2            " stavový riadok vždy
set ruler                   " pozícia kurzora
set scrolloff=5             " nechať 5 riadkov nad/pod kurzorom
set wildmenu                " ponuka pri dopĺňaní príkazov Tabom
set wildmode=longest:full,full
set linebreak               " zalamovať po slovách
set signcolumn=auto
set termguicolors           " 24-bitové farby (ak ich terminál zvládne)
colorscheme habamax         " zabudovaná schéma (Vim 9); iné: desert, slate, retrobox

" ----- Odsadenie -----
set expandtab               " Tab vkladá medzery
set tabstop=4               " šírka tabulátora
set shiftwidth=4            " o koľko odsadzuje >>
set softtabstop=4           " Backspace maže 4 medzery naraz
set autoindent
set smartindent

" ----- Hľadanie -----
set hlsearch
set incsearch
set ignorecase
set smartcase

" ----- Súbory -----
set autoread                " načítať súbor, ak sa zmenil mimo Vimu
set undofile                " história zmien prežije zatvorenie súboru
set undodir=~/.vim/undo//
set directory=~/.vim/swap//
set backupdir=~/.vim/backup//
set path+=**                " :find hľadá aj v podadresároch

" ----- Vlastné klávesové skratky -----
let mapleader = " "         " vodiaci kláves = medzerník

nnoremap <leader>w :w<CR>
nnoremap <leader>q :q<CR>
nnoremap <leader>h :nohlsearch<CR>
nnoremap <leader>e :Lexplore<CR>
nnoremap <leader>v :e $MYVIMRC<CR>

" pohyb medzi oknami bez Ctrl+w
nnoremap <C-h> <C-w>h
nnoremap <C-j> <C-w>j
nnoremap <C-k> <C-w>k
nnoremap <C-l> <C-w>l

" presun označených riadkov hore/dole
vnoremap J :m '>+1<CR>gv=gv
vnoremap K :m '<-2<CR>gv=gv

" po odsadení ostane výber
vnoremap < <gv
vnoremap > >gv

" Y kopíruje po koniec riadku (ako D a C)
nnoremap Y y$

" jk vo vkladacom režime = Esc
inoremap jk <Esc>

" ----- Automatické akcie -----
augroup moje
  autocmd!
  " vrátiť kurzor tam, kde bol pri zatvorení
  autocmd BufReadPost * if line("'\"") > 1 && line("'\"") <= line("$") | exe "normal! g`\"" | endif
  " pre HTML, CSS, JS, YAML odsadenie 2 medzery
  autocmd FileType html,css,javascript,yaml setlocal shiftwidth=2 softtabstop=2
  " Makefile potrebuje skutočné tabulátory
  autocmd FileType make setlocal noexpandtab
  " zmazať medzery na konci riadkov pri ukladaní
  autocmd BufWritePre * :%s/\s\+$//e
augroup END

1. Zabudované balíčky (bez správcu)

Neviem, čo sa deje, klávesy robia čudné veciEsc Esc. Ak treba, u niekoľkokrát vráti zmeny. Pozri vľavo dole, v akom si režime.
Vim zamrzol, nereaguje na ničPravdepodobne si stlačil Ctrl+s – terminál zastavil výstup. Odblokuj Ctrl+q.
Vim zmizol, som v termináliCtrl+z ho uspal. Vráť sa príkazom fg.
Vľavo dole recording @qOmylom si spustil nahrávanie makra. Stlač q.
Otvorilo sa malé okno s históriou príkazovStlačil si q: namiesto :q. Zavri ho :q alebo Ctrl+c.
Písmená robia príkazy, všetko VEĽKÝMIZapnutý Caps Lock – v normálnom režime sú veľké písmená iné príkazy (J, K, U…). Vypni ho a vráť zmeny u.
E37: No write since last changeNeuložené zmeny. :w a potom znova, alebo :q! na zahodenie.
E45: 'readonly' option is setSúbor je len na čítanie. Ak ho naozaj chceš prepísať, :w!.
E212: Can't open file for writingNemáš práva (systémový súbor) alebo adresár neexistuje. :w !sudo tee % > /dev/null, potom L na načítanie. Nabudúce sudoedit súbor.
E325: ATTENTION – Found a swap fileSúbor je otvorený inde, alebo Vim predtým spadol. Ak je otvorený inde, zvoľ Q a zavri ho tam. Po páde zvoľ R (Recover), skontroluj obsah, ulož a swap zmaž (:!rm .subor.swp, alebo pri ďalšom otvorení D Delete).
Vložený text sa „schodíkovito“ odsadzujePri vkladaní cez terminál Vim myslí, že píšeš a pridáva odsadenie. :set paste, vlož, :set nopaste. Lepšie: "+p.
"+y nefungujeVim bez podpory schránky (vim --version | grep clipboard → -clipboard). Nainštaluj vim-gtk3. Na Waylande ešte wl-clipboard.
Na koncoch riadkov ^MSúbor má konce riadkov z Windows. :set ff=unix a :w, alebo :%s/\r$//.
Diakritika sa zobrazuje zleIné kódovanie. :e ++enc=cp1250, a ak je to ono, :set fenc=utf-8 a :w.
Šípky vo vkladacom režime píšu A B C DBeží režim kompatibility s vi alebo vim-tiny. Nainštaluj plný vim alebo daj do .vimrc set nocompatible.
Backspace nemažeset backspace=indent,eol,start
Esc reaguje s oneskorením (v tmux)V ~/.tmux.conf: set -sg escape-time 10. Vo .vimrc: set ttimeoutlen=50.
Myšou sa nedá označiť text na kopírovaniePri set mouse=a výber riadi Vim. Drž Shift pri označovaní, alebo použi "+y.
Chyba vo .vimrc pri štarteSpusti vim -u NONE (bez konfigurácie) alebo vim --clean, oprav súbor. Postupné hľadanie: vim -V9log.txt.
Kto nastavil túto hodnotu?:verbose set shiftwidth? ukáže súbor a riadok.
