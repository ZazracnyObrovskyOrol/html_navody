Prepojenie GitHubu s Claude Code

Ako dostať projekt z GitHubu do cloudovej relácie Claude Code a ako posielať zmeny späť.

1. Verejný repozitár

Pri verejnom repozitári netreba nič nastavovať. Stačí poslať Claudovi odkaz, napríklad:

https://github.com/vlastnik/projekt

Claude ho naklonuje do relácie. Ak však chcete zmeny posielať späť (push, pull request), aj tak treba GitHub pripojiť podľa kroku 2.

2. Pripojenie GitHub účtu

  1. Na claude.ai otvorte Settings → Connectors.
  2. Pri položke GitHub kliknite na Connect a prihláste sa svojím GitHub účtom.
  3. GitHub ponúkne inštaláciu aplikácie Claude. Vyberte:
    • All repositories – prístup ku všetkým repozitárom, alebo
    • Only select repositories – len k vybraným (bezpečnejšie).
  4. Potvrďte inštaláciu a vráťte sa do Claude.
Ak repozitár patrí organizácii, správca organizácie musí inštaláciu aplikácie Claude schváliť. Bez toho sa repozitár v zozname neobjaví.

3. Pridanie repozitára do relácie

Po pripojení napíšte Claudovi názov repozitára vo formáte vlastnik/nazov, napríklad:

Pridaj repozitár mojfirma/webova-aplikacia a naklonuj ho.

Claude repozitár pridá do relácie, naklonuje ho a môže v ňom pracovať.

Pri vytváraní novej relácie na claude.ai/code môžete repozitár vybrať priamo v ponuke ešte pred začatím práce.

4. Uloženie zmien

Cloudová relácia beží v dočasnom kontajneri. Po ukončení relácie alebo po dlhšej nečinnosti sa kontajner zmaže. Preto:

  • požiadajte Claude, aby zmeny commitol a pushol do vetvy na GitHube,
  • prípadne nech vytvorí pull request, ak chcete zmeny najprv skontrolovať.
Commitni zmeny, pushni ich do novej vetvy a vytvor pull request.

Riešenie problémov

  • Repozitár sa nedá nájsť – skontrolujte, či je vybraný v nastaveniach aplikácie Claude na GitHube (GitHub → Settings → Applications → Claude → Configure).
  • Prístup zamietnutý pri push – aplikácia nemá oprávnenie na zápis alebo repozitár nie je v povolenom zozname.
  • Organizačný repozitár chýba – treba schválenie od správcu organizácie.
