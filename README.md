# HTML návody

Zbierka návodov a malých pomocných „aplikácií“ v čistom HTML.
Každá stránka je samostatný `.html` súbor, ktorý funguje v prehliadači
bez inštalácie a väčšinou aj bez internetu.

## Obsah

- **Návody**, napríklad príkazy gitu, prepojenie s GitHubom alebo nastavenie
  vývojového prostredia v MX Linuxe
- **Pomocné stránky**, napríklad úvodná stránka s odkazmi, editor odkazov
  alebo hodiny

## Použitie

Stačí otvoriť ľubovoľný `.html` súbor v prehliadači.
