VS Code a .NET na MX Linuxe

Pridanie oficiálnych repozitárov Microsoftu a inštalácia Visual Studio Code a .NET SDK. MX Linux je postavený na Debiane, takže sa používajú debianové balíky.

0. Zistite verziu Debianu

Číslo verzie Debianu budete potrebovať pri pridávaní .NET repozitára.

cat /etc/debian_version
  • 12.x → Debian 12 „bookworm“ (MX Linux 23)
  • 13.x → Debian 13 „trixie“ (MX Linux 25)

1. Príprava

Aktualizujte systém a nainštalujte nástroje na sťahovanie a overovanie kľúčov:

sudo apt update
sudo apt install -y wget gpg apt-transport-https ca-certificates

2. Ako fungujú repozitáre v MX Linuxe

Zoznam zdrojov balíkov je v týchto súboroch:

  • /etc/apt/sources.list.d/*.list – starší jednoriadkový formát,
  • /etc/apt/sources.list.d/*.sources – novší formát (deb822).

Každý repozitár tretej strany potrebuje:

  1. GPG kľúč – uložený napríklad v /usr/share/keyrings/,
  2. súbor so zdrojom v /etc/apt/sources.list.d/, ktorý na kľúč odkazuje cez Signed-By,
  3. potom sudo apt update.
Nástroj MX Repo Manager slúži len na výber zrkadla (mirror) pre repozitáre MX a Debianu. Repozitáre tretích strán, napríklad od Microsoftu, sa pridávajú ručne podľa krokov nižšie.

3. Visual Studio Code

Možnosť A: MX Package Installer (najjednoduchšie)

Otvorte MX Package Installer, v záložke Popular Applications nájdite Development → VS Code, zaškrtnite a kliknite na Install. Repozitár sa pridá automaticky.

Možnosť B: Ručné pridanie repozitára

1. Stiahnite a uložte kľúč Microsoftu:

wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > microsoft.gpg
sudo install -D -o root -g root -m 644 microsoft.gpg /usr/share/keyrings/microsoft.gpg
rm -f microsoft.gpg

2. Vytvorte súbor so zdrojom:

sudo tee /etc/apt/sources.list.d/vscode.sources > /dev/null <<'EOF'
Types: deb
URIs: https://packages.microsoft.com/repos/code
Suites: stable
Components: main
Architectures: amd64,arm64,armhf
Signed-By: /usr/share/keyrings/microsoft.gpg
EOF

3. Nainštalujte VS Code:

sudo apt update
sudo apt install code

4. Overte inštaláciu:

code --version

Aktualizácie VS Code potom prichádzajú spolu s ostatnými aktualizáciami systému.

4. .NET SDK

Pridanie repozitára Microsoftu

Microsoft poskytuje balík, ktorý pridá repozitár aj kľúč naraz. Číslo 12 v adrese nahraďte vašou verziou Debianu z kroku 0 (napr. 13).

wget https://packages.microsoft.com/config/debian/12/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb
sudo apt update

Inštalácia SDK

Pre vývoj nainštalujte SDK (obsahuje aj runtime). Odporúčaná je aktuálna LTS verzia:

sudo apt install -y dotnet-sdk-10.0

Ak projekt vyžaduje staršiu verziu, môžete nainštalovať viac SDK naraz, napríklad:

sudo apt install -y dotnet-sdk-8.0

Ak na počítači chcete aplikácie len spúšťať, stačí runtime:

sudo apt install -y aspnetcore-runtime-10.0

Overenie

dotnet --info
dotnet --list-sdks

Skúšobný projekt

dotnet new console -o Ahoj
cd Ahoj
dotnet run

5. Prepojenie VS Code s .NET

Vo VS Code otvorte rozšírenia (Ctrl+Shift+X) a nainštalujte C# Dev Kit (automaticky pridá aj rozšírenie C#). Alebo z terminálu:

code --install-extension ms-dotnettools.csdevkit

Potom otvorte priečinok projektu:

code Ahoj

Riešenie problémov

  • „Conflicting values set for option Signed-By“ – ten istý repozitár je pridaný dvakrát s rôznymi kľúčmi. Pozrite ls /etc/apt/sources.list.d/ a duplicitný súbor zmažte.
  • „NO_PUBKEY …“ – chýba kľúč alebo je zlá cesta v Signed-By. Zopakujte krok s kľúčom.
  • Balík dotnet-sdk-… sa nenašiel – skontrolujte, či verzia Debianu v adrese packages-microsoft-prod.deb sedí s vaším systémom, a spustite sudo apt update.
  • Odstránenie repozitára – zmažte jeho súbor v /etc/apt/sources.list.d/ a spustite sudo apt update.
